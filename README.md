# 🧠 Interactive Quiz Application

A responsive web-based Quiz Application developed using HTML, CSS, Bootstrap, and JavaScript. The application provides an engaging quiz experience with category selection, difficulty levels, user authentication pages, and score tracking.

---

## 🚀 Features

- User Login & Registration
- Quiz Categories
- Difficulty Levels (Easy, Medium, Hard)
- Interactive Quiz Interface
- Result Page
- User Profile Page
- Contact & About Pages
- Responsive Design
- Background Music & Sound Effects

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
